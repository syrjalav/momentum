# Privacy

Momentum Focus Dashboard does not collect or sell personal data, and it does not send dashboard content to a project server. If the user submits a Google search, the search terms are intentionally sent to Google.

The extension stores the following information locally in the user's Chrome profile:

- daily focus text
- tasks and completion status
- notes
- timer state
- selected background and rotation preference

This data is used only to restore the dashboard. The extension has no analytics, advertising, account system, remote server, or third-party API. Google is contacted only when the user intentionally submits a search.

Removing the extension also allows Chrome to remove its locally stored data.
